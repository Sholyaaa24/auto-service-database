
# База данных автосервиса

Учебный проект по проектированию реляционной базы данных для автоматизации учёта в автосервисе.

## Цель проекта

Разработать структуру базы данных для хранения информации о клиентах, автомобилях, заказ-нарядах, услугах, запчастях и оплатах.

## Структура базы данных

База данных `autoservice_db` включает 8 таблиц:

| Таблица | Назначение |
|---|---|
| client | Информация о клиентах |
| car | Автомобили клиентов |
| work_order | Заказ-наряды на ремонт |
| service | Каталог услуг |
| spare_part | Каталог запчастей |
| order_service | Услуги в заказах |
| order_part | Запчасти в заказах |
| payment | Информация об оплатах |

## Что реализовано

- Спроектирована реляционная база данных.
- Созданы 8 взаимосвязанных таблиц.
- Использованы первичные и внешние ключи (PK и FK).
- Построена EER-диаграмма.
- Разработана модель базы данных в MySQL Workbench.

## Используемые технологии

- MySQL
- SQL
- MySQL Workbench
- EER-моделирование

## Результат

Разработана учебная модель базы данных автосервиса, которая показывает принципы хранения связанных данных и проектирования реляционных баз данных.

Проект выполнен в учебных целях.
